# Drybulk LBL profile

This profile contains the four business Skills used by the ZBYL drybulk
assisted-modeling workflow. The drybulk plugin and its Java-side contracts are
maintained in the `zbyl-lean-design-simulation` project and synchronized by its
deployment scripts.

The profile intentionally excludes user configuration, credentials, sessions,
logs, caches, and unrelated Skills from the default Hermes home.
